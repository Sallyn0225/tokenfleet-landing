# TokenFleet Landing

TokenFleet landing page built with Astro. The site presents a Chinese, engineer-first product narrative for a unified AI model API gateway.

## Requirements

- Node.js 20 or newer
- npm

## Commands

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Project Structure

```text
docs/              Product and design planning notes
public/            Static assets
src/components/    Page sections and reusable Astro components
src/data/          Landing page model data
src/layouts/       Shared HTML shell and metadata
src/pages/         Astro routes
src/styles/        Global styles and design tokens
```
